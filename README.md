# fullstack_developer_capstone

## Project Overview
This project is part of the Full-Stack Software Developer Capstone Project. **Cars Dealership** is a national car retailer application in the U.S. that allows users to view dealership branches across different states, read reviews, and submit their own feedback.

## Features
- **Frontend:** Built with React and static HTML/CSS pages.
- **Backend Services:** Django web application and Express/Node.js microservices.
- **Database:** MongoDB for dealership/review data and SQLite for Django models.
- **Microservices & AI:** Sentiment analysis service deployed for review processing.
- **Containerization & CI/CD:** Dockerized services, GitHub Actions workflows, and deployment on Cloud platforms.

## Repository Structure
- `server/`: Main Django application and backend code.
- `server/frontend/`: React components and static assets.
- `server/djangoapp/`: App views, models, and API endpoints.
